# 04-parameters — 参数台账

> **唯一事实源**：所有质量、几何、惯量、K/LEGO 系数、限位、协议常量，以本目录为准。  
> 其他文档只链接，不复制数值；代码里的宏与本文冲突时，先停下来确认，不静默改。

## 文件

| 文件 | 内容 |
|---|---|
| [`parameters.md`](./parameters.md) | 参数表（已知/待测/来源/日期/口径） |

## 状态图例

| 标记 | 含义 |
|---|---|
| ✅ | 已确认（用户口述/实测/有依据的代码） |
| 🧪 | 待实测（需称重/测量/辨识） |
| ⬜ | 待确认（口径/定义/来源不明） |
| ⏸ | 硬件未装/以后再说 |

## 记录规则

1. 一行一个参数；给**值、单位、来源、日期、口径/条件**；
2. 来源优先级：实测 > 用户口述（带日期）> 当前代码 > 仿真/旧文档；
3. 代码值要写 `path:line`；仿真值要写脚本名；旧文档值标“仅参考”；
4. 不确定写 `TBD`，并链接 `docs/00-plan/todo/` 对应条目；
5. 加气弹簧/云台时新增行，不改旧行口径；质量预算单独列；
6. 每次更新在 `CHANGELOG.md` 记一条。
