## 1. 要解决的问题

1. **P0-4**：14.3 kg 是否 = 11.058（车体）+ 2×1.067（腿）+ 2×0.554（轮）？车体是否含电池/板/线/继电器？
2. **P0-5**：`vmc.cpp` 的 `k_m_leg=0.788` 与 `Chassis.h` 的 `LEG_FF_LEG_MASS=1.067` 各是什么？哪个用于力前馈/离地检测？

## 2. 为什么现在要解决

- 14.3 kg 正好等于 0.554×2 + 1.067×2 + 11.058 = 14.300，说明代码这组可能是“新数据”；
- 但 `vmc.cpp:23` 还有 0.788，且 `Chassis.h:53` 是 1.067，两者差 0.279 kg；
- 腿支持力前馈、离地检测、LQR 的等效质量都依赖这个口径；
- 不解决，参数台账无法建立，后续换气弹簧/云台也无法累加。

## 3. 目前已知（证据）

| 值 | 位置 | 含义（待确认） |
|---|---|---|
| 11.058 kg | `Chassis.h:52` `LEG_FF_BODY_MASS` | 车体质量；是否含电池/板/线未知 |
| 1.067 kg | `Chassis.h:53` `LEG_FF_LEG_MASS` | 单腿质量；含关节电机/连杆/轮毂未知 |
| 0.4 | `Chassis.h:55` `LEG_FF_WHEEL_TRACK` | 轮距（另见 TODO-04） |
| 0.554 kg | `vmc.cpp:22` `k_m_wheel` | 单轮质量；与你口述 0.55 取整差 |
| 0.788 kg | `vmc.cpp:23` `k_m_leg` | 单腿质量？与 1.067 冲突 |
| 14.3 kg | 你 2026-10-19 口述 | 车身+硬件+腿+轮，未含气弹簧/云台 |

计算：0.554×2 + 1.067×2 + 11.058 = **14.300 kg**。

## 4. 可选方案（0.788 的解释）

| 可能 | 含义 | 如何验证 |
|---|---|---|
| **A** | 0.788 是“单腿运动部件（不含轮/关节电机）”质量 | 查 `vmc.cpp` 该值用在哪、是否与 F_N 离地检测配套 |
| **B** | 0.788 是旧车腿质量，未更新 | 对比旧车资料/仿真 `m_l` |
| **C** | 1.067 含关节电机，0.788 不含 | 称重/查电机参数 |
| **D** | 其中一个是笔误 | 用整车 14.3 反推 |

## 5. 要回答它，需要做什么

1. **称重**：车体（含电池/板/线）、单腿、单轮分别称；记录日期/秤；
2. 查电机/轮毂/连杆的零件质量，与称重对照；
3. 查 `k_m_leg` 在 `vmc.cpp` 的所有使用点，判断它是“腿等效质量”还是“腿+轮”；
4. 用 14.3 反推：14.3 − 2×0.554 − 2×1.067 = 11.058，确认车体口径；
5. 明确“14.3 是否含气弹簧/云台/电池”，写进参数表。
