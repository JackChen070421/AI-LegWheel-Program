# 项目目标与当前阶段

> 最后更新：2026-10-19（基于根 README + 用户口述 + 代码抽查）  
> 事实源：本页只写“目标/阶段”，参数见 [`../04-parameters/parameters.md`](../04-parameters/parameters.md)。

## 1. 目标

做一台能在 RoboMaster 赛场使用的**轮腿平衡步兵**：

- 底盘：两条腿 + 两个驱动轮，LQR/VMC 平衡与运动；
- 功能：平地行驶、急停、原地旋转/小陀螺、上台阶、跳跃、倒地自起；
- 扩展：气弹簧（减震/储能）、云台（板1，yaw/pitch/自瞄）、板间通信；
- 最终：性能不低于旧车，重点突破二级台阶/三级台阶、跳跃、带云台稳定性。

## 3. 范围与非目标

**范围内**：
- 底盘固件、LQR/VMC/LESO、状态机、参数标定；
- 云台接口/协议（后期）；
- 实验记录、构建/烧录可复现、文档与回退。

**当前非目标**：
- 视觉自瞄算法本身（接口预留，暂不实现）；
- 比赛战术/操作手训练；
- 旧车代码复原（旧车代码暂未提供，见 [TODO-06](../00-plan/todo/06-git-baseline-deletion.md)）。
