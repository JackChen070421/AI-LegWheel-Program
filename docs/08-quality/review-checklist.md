# 交付前检查清单

> 复制到任务/PR 描述，逐项勾选；不适用写 N/A。

## 文档

- [ ] 每个数值/结论有来源（`path:line`、实测日期、用户口述+日期）
- [ ] `TBD` 都能对应到 `docs/00-plan/open-questions.md` 的编号
- [ ] 相对链接可点（至少抽查 3 个）
- [ ] 没有把“疑似/待确认”写成“确定”
- [ ] 单文档正文 ≤300 行（提案/ADR/附录不计）
- [ ] 更新了 `CHANGELOG.md`

## 代码

- [ ] 说明改了哪些文件/行为
- [ ] Keil 编译通过（或说明无法编译的原因）
- [ ] 台架/实车验证方式与结果（不能验证就写“未验证”）
- [ ] 没有顺手改无关代码
- [ ] 没有提交 build 产物/大文件

## 结构/删除/迁移

- [ ] 有快照或 git 提交可回退
- [ ] 删除清单已记录（路径/大小/原因）
- [ ] 迁移前后 manifest 对比无丢失
- [ ] Keil 工程能打开/编译
- [ ] 更新了相关文档与索引

## 安全

- [ ] 急停/限幅/电源相关改动是否单独评审？
- [ ] 是否在轮子离地/限流条件下验证？
- [ ] 是否记录失败场景与恢复方式？
