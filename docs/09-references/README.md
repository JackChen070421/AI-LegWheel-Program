# 09-references — 外部资料索引

> `researchs/` 原地保留、**只读**；本目录只建索引，不搬原文件。  
> 索引见 [`index.md`](./index.md)。

## 规则

- 不修改、不移动、不删除 `researchs/` 下任何文件；
- 新资料放 `researchs/<类别>/`，然后在本索引加一行（路径、体量、用途、许可）；
- 引用时给相对路径；对外部结论标明“参考”，不当作本项目实测；
- 大文件（视频/3D/例程）不进 git；`.gitignore` 已忽略 `researchs/`；
- 许可不明时按“仅学习参考、不得商用”处理，先问用户。

## 已知限制

- 图片/扫描件/3D/`.slx` 不能直接被 agent 读取；需要 OCR/导出/截图；
- 上交 HTML 的公式多为内嵌 base64 图片，正文可抽、公式不可读；
- PDF 是否可读取决于是否有文本层（知乎 PDF 可读；部分扫描件不行）。
